Логистическая регрессия

Что это такое?

Логистическая регрессия — это статистическая модель, которая используется для предсказания вероятности принадлежности объекта к одному из двух классов.

Несмотря на название «регрессия», это алгоритм классификации!

Математическая основа

Сигмоидная функция

P(y=1|x) = σ(w·x + b) = 1 / (1 + e-(w·x + b))

  • P(y=1|x) — вероятность принадлежности к классу 1
  • w — веса модели (коэффициенты)
  • x — признаки объекта
  • b — свободный член (bias)
  • σ — сигмоидная функция (сжимает в диапазон [0, 1])

⚙️ Гиперпараметры

Параметр Описание Диапазон Влияние
C Обратная сила регуляризации 0.01 — 1000 Меньше C = проще модель (борьба с переобучением)
max_iter Максимум итераций оптимизации 100 — 10000 Больше итераций = лучше сходимость
penalty Тип регуляризации L1, L2, None L1 = отбор признаков, L2 = стабильность
class_weight Учёт дисбаланса классов balanced, None balanced = лучше для редких классов

Плюсы и Минусы

✅ Преимущества

  • Быстрое обучение и предсказание
  • Интерпретируемые коэффициенты
  • Хорошо работает на линейных данных
  • Меньше склонна к переобучению с регуляризацией
  • Выдаёт вероятности, а не только классы

❌ Недостатки

  • Работает только на линейно разделимых данных
  • Чувствительна к выбросам
  • Требует масштабирования признаков
  • Плохо работает с нелинейными зависимостями
