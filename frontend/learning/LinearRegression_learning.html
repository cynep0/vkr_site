Линейная регрессия

Базовый алгоритм для предсказания непрерывных числовых значений

Что это такое?

Линейная регрессия — это статистический метод, который моделирует линейную зависимость между признаками (независимыми переменными) и целевой переменной (зависимой переменной).

Цель: Найти такую прямую (или гиперплоскость), которая минимизирует ошибку предсказания.

Математическая основа

Уравнение линейной регрессии

y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b + ε

  • y — предсказываемое значение (целевая переменная)
  • w₁, w₂, ... wₙ — веса (коэффициенты) модели
  • x₁, x₂, ... xₙ — признаки (входные переменные)
  • b — свободный член (intercept, сдвиг)
  • ε — случайная ошибка (шум)

Как обучается модель?

Метод наименьших квадратов (МНК)

Модель подбирает коэффициенты так, чтобы минимизировать сумму квадратов ошибок:

min Σ(yi - ŷi)²

где yi — реальное значение, ŷi — предсказанное значение.

⚙️ Гиперпараметры

Параметр Описание Диапазон Влияние
alpha Сила L2-регуляризации (Ridge) 0 — 100 Больше alpha = проще модель (борьба с переобучением)
fit_intercept Обучать свободный член (b) True / False Обычно True, кроме случаев центрированных данных
max_iter Максимум итераций оптимизации 100 — 10000 Больше итераций = лучше сходимость

Метрики качества для регрессии

Метрика Формула Интерпретация
MSE Σ(y - ŷ)² / n Средний квадрат ошибки. Чем меньше, тем лучше
RMSE √MSE Ошибка в тех же единицах, что и target. Интуитивно понятна
MAE Σ|y - ŷ| / n Средняя абсолютная ошибка. Менее чувствительна к выбросам
R² 1 - SSres/SStot Доля дисперсии, объяснённая моделью. 1 = идеально, 0 = бесполезно

Плюсы и Минусы

✅ Преимущества

  • Простота интерпретации коэффициентов
  • Быстрое обучение и предсказание
  • Хорошая база для более сложных моделей
  • Работает с небольшими выборками

❌ Недостатки

  • Предполагает линейную зависимость
  • Чувствительна к выбросам (особенно MSE)
  • Требует масштабирования признаков при регуляризации
  • Не работает с категориальным target
