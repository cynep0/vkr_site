K-Means Кластеризация

Алгоритм обучения без учителя для поиска скрытых структур и группировки объектов

Что такое кластеризация?

Кластеризация — это задача машинного обучения без учителя (unsupervised learning), цель которой — разделить объекты на группы (кластеры) так, чтобы объекты внутри одного кластера были похожи друг на друга, а объекты из разных кластеров — отличались.

Ключевое отличие: В отличие от классификации, при кластеризации нет правильных ответов (целевой переменной). Модель сама находит структуру в данных.

Что такое K-Means?

K-Means (K-средних) — это самый популярный алгоритм кластеризации, который разделяет данные на K кластеров, минимизируя расстояние от объектов до центров их кластеров (центроидов).

Алгоритм был предложен в 1967 году Джеймсом Маккуином и до сих пор широко используется благодаря своей простоте и эффективности.

Как работает алгоритм?

0

Инициализация

Выбираем количество кластеров K. Случайным образом или методом k-means++ выбираем K начальных центроидов.

1

Назначение кластеров

Каждый объект назначается ближайшему центроиду по евклидову расстоянию. Все объекты, назначенные одному центроиду, образуют кластер.

clusterᵢ = argminⱼ ||xᵢ - μⱼ||²

2

Обновление центроидов

Для каждого кластера вычисляется новый центроид как среднее арифметическое всех объектов, назначенных этому кластеру.

μⱼ = (1/|Cⱼ|) × Σ xᵢ, где xᵢ ∈ C

3

Повторение

Шаги 1 и 2 повторяются до тех пор, пока:

  • Центроиды перестанут меняться (сходимость)
  • Достигнуто максимальное число итераций
  • Изменения центроидов меньше порога

Математическая основа

Функция потерь (Inertia / WSS)

K-Means минимизирует сумму квадратов расстояний от объектов до центроидов их кластеров:

J = Σⱼ₌₁ᴷ Σ∈Cⱼ ||xᵢ - μⱼ||²

  • J — целевая функция (Inertia, Within-Cluster Sum of Squares)
  • K — количество кластеров
  • Cⱼ — множество объектов в кластере j
  • xᵢ — i-й объект
  • μⱼ — центроид кластера j
  • ||xᵢ - μ||² — квадрат евклидова расстояния

Почему квадрат расстояния?

Использование квадрата расстояния делает функцию дифференцируемой и упрощает вычисление центроидов (среднее арифметическое минимизирует сумму квадратов отклонений). Это также означает, что алгоритм чувствителен к выбросам — далёкие объекты сильно влияют на положение центроида.

Метод локтя (Elbow Method)

Один из главных вопросов K-Means: как выбрать количество кластеров K? Метод локтя помогает найти оптимальное значение.

Как работает:

  1. Обучите K-Means для разных значений K (например, от 2 до 10)
  2. Для каждого K вычислите Inertia (сумму квадратов расстояний)
  3. Постройте график: K по оси X, Inertia по оси Y
  4. Найдите «локоть» — точку, где уменьшение Inertia замедляется
Интерпретация: До «локтя» каждый новый кластер значительно улучшает качество. После «локтя» добавление кластеров даёт всё меньше пользы → это и есть оптимальное K.

Метрики качества кластеризации

Метрика Описание Диапазон Что лучше
Inertia (WSS) Сумма квадратов расстояний от объектов до центроидов 0 — ∞ Меньше (но растёт с уменьшением K)
Silhouette Score Средняя мера того, насколько объект похож на свой кластер vs другие кластеры -1 — 1 Больше (1 = идеально)
Davies-Bouldin Index Среднее сходство между кластерами (отношение внутрикластерной дисперсии к межкластерному расстоянию) 0 — ∞ Меньше (0 = идеально)
Calinski-Harabasz Отношение межкластерной дисперсии к внутрикластерной 0 — ∞ Больше

Формула Silhouette Score

s = (b - a) / max(a, b)

  • a — среднее расстояние до других объектов в том же кластере
  • b — среднее расстояние до объектов в ближайшем другом кластере

Silhouette ≈ 1: объект хорошо отнесён к своему кластеру
Silhouette ≈ 0: объект на границе кластеров
Silhouette ≈ -1: объект, возможно, отнесён к неправильному кластеру

⚙️ Гиперпараметры

Параметр Описание Диапазон Влияние
n_clusters Количество кластеров K 2 — 20 Самый важный параметр. Определяет, на сколько групп разделить данные
init Метод инициализации центроидов k-means++, random k-means++ выбирает начальные центроиды умнее → быстрее сходимость, лучше результат
max_iter Максимум итераций для одного запуска 100 — 1000 Больше итераций = лучше сходимость, но медленнее
n_init Количество запусков алгоритма 1 — 50 Алгоритм запускается n_init раз с разными центроидами, выбирается лучший результат
random_state Случайное зерно Любое целое Фиксирует случайность для воспроизводимости результатов

Плюсы и Минусы

✅ Преимущества

  • Простота реализации и понимания
  • Быстрая работа на больших датасетах O(n)
  • Масштабируемость на большие данные
  • Всегда сходится (к локальному минимуму)
  • Легко интерпретировать результаты
  • Не требует размеченных данных
  • Хорошо работает на сферических кластерах

❌ Недостатки

  • Нужно заранее указать количество кластеров K
  • Чувствителен к выбросам (outliers)
  • Предполагает сферическую форму кластеров
  • Чувствителен к масштабу признаков
  • Может сойтись к локальному, а не глобальному минимуму
  • Не работает с категориальными данными (без кодирования)
  • Плохо работает с кластерами разной плотности
