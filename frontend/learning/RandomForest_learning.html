Случайный лес (Random Forest)

Ансамблевый алгоритм на основе множества деревьев решений для классификации и регрессии

Что это такое?

Случайный лес (Random Forest) — это алгоритм машинного обучения, который строит множество деревьев решений и объединяет их результаты для получения более точного и устойчивого прогноза.

Ключевая идея: «Мудрость толпы» — коллективное решение множества простых моделей лучше, чем решение одной сложной модели.

Как работает алгоритм?

1

Bootstrapping (выборка с возвращением)

Для каждого дерева создаётся своя обучающая выборка путём случайного отбора объектов из исходных данных с возвращением. Некоторые объекты могут попасть в выборку несколько раз, другие — ни разу.

2

Случайный выбор признаков

При каждом разделении узла дерева рассматривается не все признаки, а только случайное подмножество (обычно √n для классификации или n для регрессии). Это обеспечивает разнообразие деревьев.

3

Построение деревьев

Каждое дерево строится до максимальной глубины (или до другого критерия остановки) без обрезки. Деревья получаются разными из-за случайности в выборках и признаках.

4

Агрегация результатов

Классификация: голосование большинством (majority voting)
Регрессия: усреднение предсказаний всех деревьев

Математическая основа

Предсказание случайного леса

Для регрессии (усреднение):

ŷ = (1/N) × Σ Tᵢ(x)

  • ŷ — итоговое предсказание
  • N — количество деревьев в лесу
  • Tᵢ(x) — предсказание i-го дерева для объекта x

Для классификации (голосование):

ŷ = mode{T₁(x), T₂(x), ..., Tₙ(x)}

Итоговый класс — тот, который был предсказан большинством деревьев.

Почему это работает?

Случайный лес снижает дисперсию модели по сравнению с одним деревом решений. Даже если каждое дерево переобучается (высокая дисперсия), усреднение многих независимых деревьев компенсирует индивидуальные ошибки. Чем меньше корреляция и больше деревьев, тем ниже дисперсия ансамбля.

Формула дисперсии ансамбля:

Var(ensemble) = ρ × σ² + (1-ρ) × σ² / N

  • ρ — корреляция между деревьями
  • σ² — дисперсия отдельного дерева
  • N — количество деревьев.

⚙️ Гиперпараметры

Параметр Описание Диапазон Влияние
n_estimators Количество деревьев в лесу 10 — 500 Больше деревьев = выше точность, но медленнее обучение. После определённого предела выгода снижается
max_depth Максимальная глубина каждого дерева 1 — 100 (None = без ограничений) Меньше глубина = проще модель, меньше переобучение. Больше глубина = модель сложнее
min_samples_split Мин. объектов для разделения узла 2 — 20 Больше значение = деревья меньше ветвятся, снижается переобучение
min_samples_leaf Мин. объектов в листовом узле 1 — 10 Больше значение = сглаживание модели, особенно важно для регрессии
max_features Признаков для рассмотрения в каждом разделении sqrt, log2, auto, число Меньше признаков = больше разнообразие деревьев. sqrt — рекомендуется для классификации
bootstrap Использовать ли выборку с возвращением True / False True — стандартный режим. False — все деревья обучаются на всех данных

Важность признаков (Feature Importance)

Одно из ключевых преимуществ случайного леса — возможность оценить, какие признаки наиболее важны для предсказания. Это вычисляется на основе уменьшения неопределённости (Gini importance): Для каждого признака суммируется, насколько он уменьшает неопределённость во всех узлах всех деревьев, где он использовался.

Преимущество: В отличие от линейных моделей, важность признаков в случайном лесу учитывает нелинейные взаимодействия между признаками.

Плюсы и Минусы

✅ Преимущества

  • Высокая точность в большинстве задач
  • Устойчив к переобучению (благодаря усреднению)
  • Работает с категориальными и числовыми признаками
  • Не требует масштабирования данных
  • Устойчив к выбросам и шуму в данных
  • Оценивает важность признаков
  • Поддерживает и классификацию, и регрессию

❌ Недостатки

  • Медленнее линейных моделей (особенно на больших данных)
  • Требует больше памяти (хранение множества деревьев)
  • Менее интерпретируем, чем одно дерево решений
  • Не экстраполирует за пределы обучающих данных (для регрессии)
  • Может переобучаться на зашумленных данных при большой глубине
  • Предсказания не калиброваны по вероятности (для классификации)
